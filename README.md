Python 1.0 — Reconstructing the original archive

The original Python 1.0 archive is divided into two parts because of GitHub file-size restrictions.

Download both files:

- "python_1.0.part1"
- "python_1.0.part2"

Linux, macOS and Termux

cat python_1.0.part1 python_1.0.part2 > python_1.0.tar.gz

Windows (CMD)

copy /b python_1.0.part1+python_1.0.part2 python_1.0.tar.gz
